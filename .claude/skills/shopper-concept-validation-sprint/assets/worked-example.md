# Synthetic worked example

Input: Merchant considers a bundle selector. Risk: shoppers cannot tell which bottle size each bundle contains. Two concepts: explicit contents table versus image-only cards. Prototype only the selection screen with verified bundle facts.

Task: choose the bundle containing two 750 mL bottles. Predeclared criterion: any wrong selection triggers label/layout revision before launch. Synthetic P1 chooses correctly; P2 mistakes 500 mL for 750 mL. Decision: revise; not evidence that the bundle lacks demand.

Boundary scenario 1: Participants say they “would buy”. Record stated intent, not forecast revenue.
Boundary scenario 2: Prototype omits shipping cost. Do not draw conclusions about checkout willingness or total-price acceptance.
