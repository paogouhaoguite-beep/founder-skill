# Product image shot list

> By [ShopChief](https://shopchief.ai/?utm_source=product-image-shot-list&utm_medium=agent_skill&utm_campaign=commerce_skills&utm_content=skill) · Practical workflows for independent ecommerce and DTC sellers. No ShopChief account required.

## Work from the real item
Read SKU/variant specifications, existing photos, size/material facts, brand styling, target placements and production constraints. Viewing images is required before claiming visible defects or coverage; without image access use an asset inventory supplied by the merchant and label visual judgments unverified. No image tool or paid service is required to write a shot list.

Identify the buyer decisions a photo must resolve: silhouette, scale, included pieces, material texture, mechanism, fit and use limitation. Map existing assets to those questions before requesting new production. Never portray a feature or accessory the actual SKU lacks.

## Design shots by purpose
For each proposed shot specify product/variant, decision answered, camera angle/distance, orientation/crop, lighting/background, props, action, factual reference and retouching boundary. Distinguish factual product demonstration from lifestyle atmosphere. Scale must use a known reference or supplied measurement; avoid compositing that changes apparent size or performance. Required main-image/background rules depend on destination and must be checked against current platform guidance.

Build a continuity sheet for color, logo orientation, included hardware and variant differences. State which shots require physical photography and which can use existing licensed assets or clearly marked concepts. Do not claim generated imagery documents a real durability, fit or waterproof test. Capture size/care/usage constraints through faithful detail rather than cosmetic alteration.

## Production handoff
Deliver a shot matrix, prioritized coverage gaps, asset filenames, crop derivatives, alt-text drafts describing actual visible content, and a factual approval checklist. Keep overlays separate from source images where the destination requires it. List unresolved claims/assets before production starts.

A brief is not an image delivery. Generate or edit only with an available tool and user-authorized scope; no paid batch, model booking or photographer outreach is implied. After actual production, inspect outputs against the continuity sheet before calling them ready.
