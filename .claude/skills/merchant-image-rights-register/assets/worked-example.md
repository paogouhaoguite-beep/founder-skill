# Synthetic worked example

Input: A free-to-view photographer image has no license statement; a merchant-owned product photo has documented ownership and sufficient resolution. Intended use: paid ad.

Register: A/photographer image—rights unknown, blocked for production, inspiration only; B/merchant photo—ownership supplied, candidate for ad, verify depicted SKU and required releases if people appear. Select B for the production brief; retain A’s URL only as a style reference.

Boundary scenario 1: A stock license says editorial-only. Do not use it in a product advertisement.
Boundary scenario 2: A model release is required but absent. Mark that use unresolved rather than assume the stock marketplace handled it.
