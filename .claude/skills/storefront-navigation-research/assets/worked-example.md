# Synthetic worked example

Input: Store labels bags as “Urban”, “Transit” and “Escape”. Shoppers need a bag for a14-inch laptop. Text-tree test task: “Find a bag suitable for carrying your laptop to work.” Correct destinations are preverified commuter-compatible categories.

Synthetic results: P1 enters Transit and finds the correct item; P2 enters Urban then backtracks; P3 cannot choose. Report 1/3 direct successes,1/3 indirect and 1/3 noncompletion for this sample. Proposal: test clearer use-case labels with compatibility facts; do not claim a storewide conversion lift.

Boundary scenario 1: Merchant wants only current menu labels tested. Use closed sorting/tree tasks; do not present an open sort as validation of a fixed hierarchy.
Boundary scenario 2: Participants select different valid paths. Preserve multiple acceptable routes instead of scoring one as failure after the fact.
