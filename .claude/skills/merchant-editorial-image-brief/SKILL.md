# Merchant Editorial Image Brief

## Inputs
Collect actual article/video content, intended reader, placement/aspect ratio, title, product references, brand direction and rights. A slot-by-slot image brief is sufficient without generation tools. A thumbnail must represent the actual content, not a fabricated result.

## Brief the visual roles
Read the content and identify where an image explains a concept, demonstrates a product, breaks a dense section or summarizes the main promise. Do not add an illustration at every heading by habit. Separate cover/thumbnail attention from body-image explanation.

For each slot specify message, subject, composition, camera/view, product-lock constraints, text zone and caption/alt text. Choose a consistent style/palette/type treatment across the set; a style change alone does not make a new skill or factual claim. Use the title and image as complementary signals rather than duplicate dense text.

Check references and licensing, then produce only with available authorized tools. Inspect crops at target size and compare every depicted feature with source facts. Avoid fake before/after results, manufactured authority badges, invented people’s endorsements or misleading product scale.

## Deliver
Return image-slot map, finished prompts/production briefs, source/rights register and any actual generated artifacts with QA status. Do not promise click-through improvements without a valid test.
