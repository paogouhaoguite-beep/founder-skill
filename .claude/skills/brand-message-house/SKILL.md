# Brand Message House

Use this when a DTC merchant needs a product positioning and message-house matrix linking buyer alternatives, attributes, benefits, proof and objections.

## Merchant inputs

Current product specifications; actual availability; target buying situation; customer quotations; named alternatives; proof for differentiators; existing approved positioning.

Separate supplied facts, observed evidence, assumptions and unavailable information. Request only missing inputs that change the decision; a partial evidence set supports a partial result, not invented measurements.

## Tools and fallback

Read supplied CSV, screenshots, page text or documents with available file tools. A browser or authorized read-only connector can verify current pages and provider documentation. No named commercial service, host registry or script is required. Without live access, use dated exports and label the access window; do not imply a live check. Verify current provider-specific formats and policies before implementing a platform change.

## Procedure

1. Name what a buyer would do without the product, including delay, keep an existing item or choose another category. Separate observed alternatives from the team’s guesses.

2. Map each distinctive attribute to a practical benefit and a buyer-valued outcome. Remove chains that stop at an internal feature name.

3. Use customer language to identify push, pull, anxiety and habit. Preserve supporting quote IDs and avoid treating a few interviews as market prevalence.

4. Reconcile differentiators to what can ship now, by SKU and market. Aspirational future features and unsupported superiority claims cannot anchor today’s promise.

5. Build one core promise with a small set of pillars; each pillar needs an audience, supporting fact, proof source and objection response. Expose proof gaps rather than filling them with superlatives.

6. Test the promise against named alternatives. If the same statement honestly fits each alternative, narrow the situation or articulate a supported distinction. Publish neither exclusive nor comparative claims merely because a positioning exercise prefers them.

7. State brand purpose separately from evidence of customer preference or willingness to pay. Proposed differentiation must survive comparison with named alternatives; brand equity cannot be inferred from internal enthusiasm or a uniqueness sentence.

## Deliverable

A product positioning and message-house matrix linking buyer alternatives, attributes, benefits, proof and objections.

Include input provenance and observation dates beside affected rows. Explain the decision and the uncertainty it depends on; preserve exclusions and unresolved rows so another operator can reproduce the result.
