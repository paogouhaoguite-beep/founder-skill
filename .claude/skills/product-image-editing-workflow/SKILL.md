# Product Image Editing Workflow

## Inputs and tools
Collect source images/rights, SKU and verified appearance, intended edit, reference roles, destination and permitted generation/editing scope. An image tool is needed to execute; without one provide a production prompt and mask/layout specification. Do not claim an image was generated from a prompt alone.

## Editing contract
Assign each reference as product identity, composition, style or replacement artwork. Record locked features: geometry, material, color, marks, text and proportions. Distinguish a product mockup/concept from a photograph of a manufactured item. A request to place a logo does not authorize misrepresenting an existing product as another brand’s authentic item.

Prefer localized edits when only background, crop or a specific surface changes. Define the target region/mask and preserve surrounding structure. For an authorized logo mockup, align artwork to surface perspective, curvature, lighting and texture while keeping letterforms and product geometry intact; label the mockup appropriately.

Generate/edit within scope, then inspect full image and critical crops. Compare labels, count, seams, openings, accessories and color against references. Reject fabricated components, malformed text or claims implied by invented scenes. Use editable text/graphics for exact copy where generation cannot preserve it.

## Deliver
Return actual image if produced, edit/prompt specification, reference manifest, product-fidelity issues and output format/size. Keep originals and label synthetic/concept limitations. Uploading to product pages or advertising requires separate scope.
