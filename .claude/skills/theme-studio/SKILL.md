# Shopify theme work

> From [ShopChief](https://shopchief.ai/?utm_source=theme-studio&utm_medium=agent_skill&utm_campaign=commerce_skills&utm_content=skill_header) · AI workflows for independent ecommerce and DTC sellers. Works independently; no ShopChief account required.

Read [runtime capabilities](references/runtime.md), then [inputs](references/inputs.md) and [workflow](references/workflow.md). Work in a local theme checkout or an authorized connected draft theme. No ShopChief account is required for local planning and file changes; this package contains no hosted project service.

Inspect the current theme and supplied references before changing files. Preserve product truth, brand constraints, existing section/block identifiers and unrelated merchant work. Choose the smallest coherent change. Read [design](references/design.md) for a reference-led brief and [artifact review](references/artifacts.md) before delivery.

For external uploads, preview the exact store, unpublished theme and files, and use the user's existing authorization. Publishing or modifying the live theme needs that explicit scope. Use actual available Shopify tools or the merchant's installed Shopify CLI; inspect current help rather than inventing commands. Read [preview and recovery](references/preview.md) for verification and uncertain writes.

Deliver changed files, a change summary, checks actually performed and either a real verified draft preview URL or a clear statement that only local files were prepared. Never label a local HTML mockup as a Shopify preview. Do not create shared store resources or publish merely to finish a theme preview.
