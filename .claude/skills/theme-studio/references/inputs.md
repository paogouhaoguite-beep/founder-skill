# Inputs and target

Identify create versus edit, store, theme ID/name and live/draft status, local checkout, affected pages, supplied references and reusable product/brand assets. Ask only for an ambiguity that could select the wrong store/theme or invalidate the deliverable. Do not require a new project for ordinary design advice.

For reference sites/screenshots, describe the desired layout, spacing, hierarchy and interaction while retaining the merchant's own brand and licensed assets. A screenshot cannot prove hover, mobile or checkout behavior. Record unknowns.
