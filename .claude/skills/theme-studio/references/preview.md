# Preview and recovery

A real preview must belong to the intended store and unpublished theme and contain the new file revision. Verify the page visually when possible. A local screenshot or successful API response alone does not establish that condition.

After an uncertain upload, inspect theme IDs, current files and provider task state before retrying. Do not switch to the live theme to bypass a draft upload failure. Preserve prior artifacts and explain the blocker. Rollback uses a reviewed prior file revision and its own correct target; cancellation is not rollback.
