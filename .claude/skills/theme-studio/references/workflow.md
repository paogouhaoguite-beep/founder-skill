# Theme workflow

1. Inspect the current files and working-tree status. Identify supported sections, templates, settings and reusable blocks. Keep a change manifest in the local working folder.
2. Translate the merchant's request into page/section changes with acceptance criteria. Reuse confirmed scope; obtain a decision before material unspecified brand or structural changes.
3. Edit only scoped theme files. Keep Liquid, JSON templates and schema valid. Avoid overwriting merchant changes or adding dependencies without purpose.
4. Run available theme syntax/static checks and inspect local previews at relevant widths. Record missing preview access; a static check does not prove rendered behavior.
5. For a requested upload, identify the exact draft theme and changed files. Use authorized connected tools or an installed Shopify CLI after inspecting its actual help. Preserve the live theme unless explicitly authorized.
6. Read back uploaded files/status and inspect the actual preview. Reconcile ambiguous uploads before retrying. Do not repeat a upload just because its receipt was delayed.
7. Save file paths, theme identity, revision and actual results so continuation starts from artifacts rather than an old chat claim.
