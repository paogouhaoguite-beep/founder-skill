# Synthetic worked example

Input: A reusable bottle merchant is choosing a coating test plan. Candidate expert personally ran factory QA last quarter but also sells coatings. The call budget is 20 minutes.

Guide: 0–3 min establish role and confidentiality; 3–8 min “Walk me through the last coating batch you evaluated”; 8–14 min “What made you investigate further?” followed by “What records supported that?”; 14–18 min “Describe a case where the same test gave a different practical result”; 18–20 min request public test-method references.

Evidence-log result from a synthetic call: E1 says abrasion failures occurred near the cap; firsthand recalled account; no batch records supplied; commercial incentive disclosed. Decision: use the account to add a cap-contact test question to the lab brief, not to claim a failure rate.

Boundary scenario 1: The expert offers another brand’s confidential test report. Decline it and request a public method description instead.
Boundary scenario 2: Only an executive with no recent hands-on role is available. Label their perspective as strategic opinion and leave process-performance questions unresolved.
