# Synthetic worked example

Input: Product price 30, variable cost 18, fixed cost 600; base units 100, downside units 60. Sheets: Inputs and Model. Model revenue=price×units; contribution=(price−cost)×units; operating result=contribution−fixed cost.

Base: revenue 3,000, contribution 1,200, result 600. Downside: revenue 1,800, contribution 720, result 120. Break-even units 600/(30−18)=50 under this simplified linear model. Check: result+fixed cost=contribution for both scenarios. Taxes, returns and stock constraints are absent and explicitly out of this fixture.

Boundary scenario 1: Price equals variable cost. Break-even units is undefined for positive fixed cost; do not hide division by zero.
Boundary scenario 2: A workbook library writes formulas but cannot recalculate them. Deliver formulas with hand-checked fixture values and mark target-app recalculation not run.
