# Delivery example and acceptance

Illustrative pattern: a mobile variant selector hides the chosen size. Show the observed page/viewport, a concrete selector/label change, exact replacement copy, and the checkout-completion guardrail. If no analytics exist, call this a heuristic finding, not a measured conversion cause.

Accept only findings tied to the inspected page, finished requested copy/assets, feasible implementation instructions and a baseline/verification method. Do not deliver a generic CRO checklist as if it were a page audit.
