# Worked example

All names, inputs and results below are synthetic.

Input: Premium repairable bags propose disposable low-price totes. Core evidence says customers value repairability; no demand for disposable items is supplied. Expected memo flags promise conflict even if unit margin looks attractive. Test a repairable entry-level tote or a clearly separated proposition before applying the same premium claim. An email list is an asset, not proof that customers want this category.

## Acceptance scenarios

1. Given the extension uses a different quality standard, surface the promise/quality gap instead of borrowing the core product’s test claims.

2. Given strong stated interest but no purchase evidence, label demand provisional and stage stock investment.
