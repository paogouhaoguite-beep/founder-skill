# Worked example

All names, inputs and results below are synthetic.

Input: Mature spend $2,400, 80 purchases, $8,000 credited revenue. Achieved CPA = $30 and ROAS = 3.33×. A proposed $10 tCPA has no support from this baseline; explain the volume/efficiency tradeoff and test a merchant-agreed feasible target instead. A recent two-day window with unconverted clicks is not comparable if lag is seven days.

## Acceptance scenarios

1. Given only revenue is supplied, do not label the bidding objective profit-maximizing.

2. Given signal volume is insufficient for a platform’s current eligibility, mark the strategy unavailable and verify alternatives rather than force it.
