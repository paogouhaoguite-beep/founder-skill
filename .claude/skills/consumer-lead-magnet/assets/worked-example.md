# Worked example

All names, inputs and results below are synthetic.

Input: A linen store receives repeated questions about table sizes. Artifact sample: “For a 140×80 cm table and 25 cm drop on each side, choose 190×130 cm.” Capture page promises a sizing worksheet, not an invented exclusive discount. Of 100 requests, 92 deliveries and 15 later orders, report delivery rate 92%; do not assume every later order was caused by the worksheet.

## Acceptance scenarios

1. Given the resource repeats measurements already essential to choose a product, keep those basic facts public and add independent useful guidance.

2. Given a requester declines marketing, deliver the requested resource under the allowed fulfilment basis without enrolling them in promotions automatically.
