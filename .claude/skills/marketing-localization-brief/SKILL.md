# Marketing Localization Brief

Use this when a DTC merchant needs a market-specific marketing localization brief separating immutable product facts from adaptable language, imagery and offer presentation.

## Merchant inputs

Target market/language; product and offer facts; local customer research; units/currency; shipping/returns constraints; current creative; glossary and brand rules.

Separate supplied facts, observed evidence, assumptions and unavailable information. Request only missing inputs that change the decision; a partial evidence set supports a partial result, not invented measurements.

## Tools and fallback

Read supplied CSV, screenshots, page text or documents with available file tools. A browser or authorized read-only connector can verify current pages and provider documentation. No named commercial service, host registry or script is required. Without live access, use dated exports and label the access window; do not imply a live check. Verify current provider-specific formats and policies before implementing a platform change.

## Procedure

1. Distinguish language translation from market adaptation. Map which buying situations, proof, payment expectations and delivery promises actually change.

2. Build a locale brief with audience evidence, tone, terminology, units, currency presentation and support availability. Never assume language equals country.

3. Audit source offers for eligibility, deadlines, stock and service promises before adapting them; a phrase cannot make an unavailable benefit available.

4. Create a transcreation matrix: preserve exact facts, adapt examples and imagery, and flag regulated or ambiguous claims for appropriate review.

5. Specify native review and in-context layout checks for product, checkout and campaign surfaces. Include text expansion and right-to-left needs when relevant without prescribing an unverified framework migration.

6. Return approved versus pending decisions with owners. Measure locale performance using comparable traffic and fulfillment conditions, not translation word count.

7. Classify each content block as translate, localize or transcreate, and keep approved regulatory wording exact. Build local keyword evidence rather than translate US keywords; log cultural hypotheses as hypotheses, not stereotypes. Request an in-market reviewer for meaning, terminology and cultural context; back-translation can reveal drift but is not certification. Replace weighted quality scores with issue-level review and current jurisdiction-specific evidence.

## Deliverable

A market-specific marketing localization brief separating immutable product facts from adaptable language, imagery and offer presentation.

Include input provenance and observation dates beside affected rows. Explain the decision and the uncertainty it depends on; preserve exclusions and unresolved rows so another operator can reproduce the result.

A proposed change is not a completed action; report completion only from provider or page readback. Do not copy credentials or customer contact details into reports.
