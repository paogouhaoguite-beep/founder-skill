# Creator Campaign Budget

Use this when a DTC merchant needs an all-in creator campaign budget with comparable quote normalization, deliverable plan and explicit contribution scenarios.

## Merchant inputs

Campaign goal; creator deliverables; comparable dated quotes; product and shipping costs; usage rights; amplification and staff costs; available budget and return assumptions.

Separate supplied facts, observed evidence, assumptions and unavailable information. Request only missing inputs that change the decision; a partial evidence set supports a partial result, not invented measurements.

## Tools and fallback

Read supplied CSV, screenshots, page text or documents with available file tools. A browser or authorized read-only connector can verify current pages and provider documentation. No named commercial service, host registry or script is required. Without live access, use dated exports and label the access window; do not imply a live check. Verify current provider-specific formats and policies before implementing a platform change.

## Procedure

1. Build an all-in cost ledger separating creator fees, samples at economic cost, shipping, production, licensing, amplification and tools.

2. Compare quotes only when market, platform, deliverable count, production effort and rights are compatible. Missing quotes become requests, not invented tier rate cards.

3. Allocate the stated cap across eligible deliverables and operational costs. A contingency is explicit and merchant-chosen; all line items reconcile to the total.

4. Model revenue and contribution scenarios from supplied clicks, conversion, AOV, returns and variable costs. Keep media-equivalent value separate from cash revenue.

5. Tie each deliverable to the campaign objective, acceptance condition and rights window. Reduce scope or test size when the feasible plan exceeds budget.

6. Return alternative allocations with tradeoffs and a reallocation rule based on comparable evidence, not follower tier or an automatic “winner” label.

## Deliverable

An all-in creator campaign budget with comparable quote normalization, deliverable plan and explicit contribution scenarios.

Include input provenance and observation dates beside affected rows. Explain the decision and the uncertainty it depends on; preserve exclusions and unresolved rows so another operator can reproduce the result.
