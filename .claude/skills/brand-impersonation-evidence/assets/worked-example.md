# Worked example

All names, inputs and results below are synthetic.

Input: A lookalike site copies the official logo and falsely claims to be the brand’s clearance outlet. Expected packet includes both URLs, screenshot timestamps, exact false statement and official ownership evidence. A customer’s card number is removed from the support screenshot. A drafted abuse report is labelled draft; no takedown is claimed.

## Acceptance scenarios

1. Given a reseller accurately identifies itself, do not label it impersonation solely because it sells the product.

2. Given the page is unavailable, preserve the earlier screenshot and mark current status unknown rather than inventing a live capture.
