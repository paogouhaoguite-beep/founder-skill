# Review optimization results / 复查优化效果

This is the normal third phase of `site-seo-audit`, even when performance has not declined. `content-decay-diagnosis` investigates a demonstrated decline; do not invent decay to invoke it.

1. Load the named workspace artifact and original issue IDs, tenant/store, pages, modifications, dates and baseline window. If missing, reconstruct only from supplied evidence and mark the absent baseline; do not claim a measured improvement.
2. Verify technical repairs immediately: status, robots, canonical, real markup, links, relevant template and backend fields vs rendered storefront. Keep the original issue ID; mark fixed only when its acceptance checks pass, otherwise open/partially verified.
3. Compare SEO performance over matched market/device/query/page and comparable periods. Use authorized GSC data or exports for impressions/clicks/index evidence, and label provider rankings/traffic as estimates. Record seasonal, promotional and attribution differences and reporting lag. No data yet is not no effect; propose a justified observation window.
4. Re-run the same AI platform, market, language and question set at a recorded time only within current authorization/budget. Separately report mentions, cited URLs and factual accuracy with denominators. Provider mention libraries, actual search-interface samples and ordinary model API answers are different instruments, never a combined score. A one-time sample proves neither general exposure nor future citation.
5. Separately report identifiable business outcomes (GA4 engagement/referrals, orders/revenue with source and attribution limits) only when actually available. Never infer orders from search volume, revenue from citations or causality from a before/after correlation.
6. Deliver a before/after table, issues closed/open/unverified, new evidence references, confounders and next actions. Update the same ledger and link to its original baseline. Suggest the next review without starting scheduled monitoring.

中文：正常复查由全站入口负责；只有存在下降证据才进入下降诊断。复用原成果、问题 ID、修改记录和基线，分列技术验证、SEO 表现、AI 提及/引用/准确性、可识别经营结果。窗口和口径须可比，无数据不等于无效果，相关不等于因果。保留未验证项，不虚构改善或持续监测。
