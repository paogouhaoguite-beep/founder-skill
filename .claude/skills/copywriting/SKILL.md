# Commerce copywriting

> From [ShopChief](https://shopchief.ai/?utm_source=copywriting&utm_medium=agent_skill&utm_campaign=commerce_skills&utm_content=skill_header) · AI workflows for independent ecommerce and DTC sellers. Works independently; no ShopChief account required.

Deliver finished copy for the requested product, landing page, ad or email. Reuse the merchant brief, verified product facts and connected catalog before asking questions. Ask only for missing facts that prevent accurate copy. Do not pause for a mandatory copy-brief approval: include a short assumptions note with the draft when useful.

## Choose the output
- Product/PDP/bulk listing copy: read [product listing mode](references/product-listing-mode.md), and the platform rules only for the requested platform.
- Landing page: headline, value proposition, benefits with proof, objections and CTA; adapt length to the page.
- Ads: final copy variants grouped by audience/intent and placement, with truthful claims and the verified field constraints. Do not deliver only a strategy.
- Email: subject, preview text, body, CTA and relevant audience/trigger. Publishing/sending is a separate authorized action.

## Evidence into copy
For SEO or search-ad copy, reuse fresh market-matched keyword evidence. If missing and it changes the wording, read [DataForSEO contract](references/dataforseo-contract.md), query a focused keyword overview and inspect SERP only where intent is uncertain. Batch a supplied list within its authorized scope. Prefer actual buying intent and product fidelity over raw volume; never change material, compatibility or features to fit a popular keyword. No paid research is needed for a simple wording edit with sufficient context.

Write in the requested storefront/customer language; explain to the merchant in their conversation language. Benefit claims must trace to facts. No invented reviews, certifications, scarcity, guarantees or compare-at prices. Missing optional specifications can be omitted; do not output placeholders as publishable facts.

## Delivery and handoff
Deliver usable text first. Include alternatives only where useful, plus a compact field/source or assumption note. For bulk work preserve product identifiers and return import-ready columns. Save the artifact through available workspace tools and report its reference; if unavailable, deliver inline without claiming persistence.

If the user requested a broader launch/content task, pass the completed copy and evidence to the available next workflow without restarting research. Preview exact external changes and use existing authorization/confirmation rules before writing or publishing. Never request credentials in chat.

## Specialist routing
Long-form keyword-based merchant blogs use available blog-article-writer guidance for article SEO/GEO, merchant images and internal links. Keep product, landing-page, ad and email copy here.
