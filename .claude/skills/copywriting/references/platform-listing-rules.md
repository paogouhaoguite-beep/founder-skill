# Platform Listing Rules

Use this reference after `product-listing-mode.md` when platform-specific output is needed.

## Shopify / DTC

- Title: clear product name plus primary differentiator.
- Description: brand voice is allowed; structure with scannable sections.
- SEO title: usually 50-60 characters.
- SEO meta description: usually 140-160 characters.
- Include sections for benefits, details, care/use, shipping/returns only when facts are available.
- Avoid marketplace-style keyword stuffing; DTC pages should feel brand-native.

## Amazon

- Title: include brand, product type, key attribute, quantity/size, and differentiator when known.
- Bullets: 5 bullets, each with one benefit and supporting fact.
- Description/A+ copy: use short modules, comparison tables, and visual copy blocks.
- Avoid prohibited medical, cure, guarantee, exaggerated ranking, or unverifiable superiority claims.
- Do not fabricate backend keywords or competitor terms.

## eBay

- Title: concise and search-readable.
- Description: mention condition, compatibility, dimensions, included items, and shipping/returns when known.
- Item specifics matter; ask for missing compatibility or condition if it is blocking.
- Keep promotional language secondary to buyer confidence.

## Etsy

- Title: product type, style, material, recipient/use case, and occasion when known.
- Tags: use varied buyer-search phrases, not repeated single words.
- Description: handmade/process/story can matter, but facts still come first.
- Include personalization, care, dimensions, processing time, and materials only when known.

## TikTok Shop

- Title: short, search-friendly, benefit-forward.
- Description: hook first, then features, use cases, package contents, and offer.
- Visual alignment matters: if images/video are requested, hand off to `image-prompt-guide` for visuals and keep this skill focused on text.
- Avoid claims that require proof unless the user supplied proof.

## Generic Marketplace

Use this fallback when the platform is unknown:

- Title: `[Product Type] with [Primary Benefit/Differentiator]`
- Bullets: 3-5 concise benefit bullets.
- Description: problem, solution, proof/facts, use cases, CTA.
- SEO: primary keyword in title and first paragraph, secondary keywords naturally distributed.
