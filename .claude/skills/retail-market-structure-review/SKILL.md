# Retail Market Structure Review

Use this when a DTC merchant needs a category-structure and macro-risk evidence table, capability/option comparison, scenario arithmetic and a bounded expansion recommendation.

## Merchant inputs

A product category, target geography/time window, merchant strengths/costs, observed competitor/substitute offers, supplier options, and dated economic/regulatory evidence relevant to a specific expansion decision.

Separate supplied facts, observed evidence, assumptions and unavailable information. Request only missing inputs that change the decision; a partial evidence set supports a partial result, not invented measurements.

## Tools and fallback

Read supplied CSV, screenshots, page text or documents with available file tools. A browser or authorized read-only connector can verify current pages and provider documentation. No named commercial service, host registry or script is required. Without live access, use dated exports and label the access window; do not imply a live check. Verify current provider-specific formats and policies before implementing a platform change.

## Procedure

1. Define the category boundary and merchant decision. Separate category attractiveness from whether this merchant can win; market growth or funding announcements alone do not establish profitable demand.

2. Build a five-forces evidence table: entry barriers, supplier concentration/switching constraints, shopper alternatives/price sensitivity, substitutes meeting the same job, and rivalry/differentiation. Qualitative high/medium/low labels require an explicit rationale and contrary evidence; do not average them into a scientific score.

3. Screen political/economic/social/technical/legal/environmental changes only where a causal path to demand, costs, access or risk is stated. Distinguish enacted requirements from proposals and forecasts from measured history; verify current authoritative rules before acting.

4. Separate internal strengths/weaknesses from external opportunities/threats. Match actual capabilities to opportunities and vulnerabilities to threats. Avoid using generic category growth as a merchant strength.

5. Model decision-sensitive base/downside scenarios using supplied units, prices and costs. If computing historical or forecast CAGR, use (end/start)^(1/years)−1 with positive comparable endpoints; label projected endpoints. A change in definition invalidates the comparison.

6. Deliver an evidence-linked market memo with option, economic mechanism, uncertainty, reversible test and review trigger. Select frameworks that answer the question; no required report length, force count score or unsupported quantified upside.

## Deliverable

A category-structure and macro-risk evidence table, capability/option comparison, scenario arithmetic and a bounded expansion recommendation.

Include input provenance and observation dates beside affected rows. Explain the decision and the uncertainty it depends on; preserve exclusions and unresolved rows so another operator can reproduce the result.
