# Synthetic worked example

Input: Merchant wants a damaged-parcel intake SOP. Approved policy requires order match and photo review before remedy decision.

SOP: 1 Support verifies order identity from the private ticket; result matched order ID. 2 Record damage description and supplied photo reference; result evidence packet, or missing-evidence request draft. 3 Apply dated policy and propose remedy; exceptions go to owner. 4 Execute only an authorized remedy, then verify its actual status. 5 Draft the shopper update with that status. Done means case record and verified remedy/deliberate hold, not merely an email draft.

Boundary scenario 1: No photo exists. Follow the merchant policy’s alternate evidence path or escalate; do not invent a photo requirement if policy permits other evidence.
Boundary scenario 2: Refund request times out. Check provider state before retrying to avoid duplicate payment.
