# Synthetic worked example

Input: Synthetic return log contains 12 fit-related returns among 100 delivered bag orders in September. Two interview snapshots show shoppers could not judge laptop fit. The outcome is to reduce fit-related returns in a comparable future cohort while monitoring overall returns.

Tree: outcome → uncertainty about laptop fit → (A) verified compatibility table or (B) dimensions video. Assumption A1: shoppers can locate and correctly use the table. Test: prototype task with supplied laptop dimensions, observe correct variant selection without hints. Merchant predeclares that any observed wrong selection triggers a design revision; this is a diagnostic rule, not a statistical guarantee.

Evidence: baseline 12/100 = 12% for that cohort. No expected reduction is claimed. A completed prototype is not proof the return rate changed.

Boundary scenario 1: Leadership insists on a video with no supporting research. Keep it as a solution hypothesis and identify the need it is intended to address.
Boundary scenario 2: A fake “buy now” test would collect money for unavailable stock. Replace it with a clearly labeled concept-interest test and state its weaker behavioral evidence.
