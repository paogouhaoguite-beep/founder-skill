# 商品详情页整套图片制作

围绕商品购买问题，制作按顺序展示的详情页图片组：主图、具备证据的细节模块和可读的移动端版本。负责模块次序、事实依据与整套图片一致性，不只是把单张商品图换背景。

## 所需输入

收集 SKU／规格、商品原图、已批准事实与细节照片、模块顺序或购买问题、准确文案、品牌图形，以及已知的桌面／移动展示尺寸。每个模块都对应参考图和有依据的主张，标出缺少的示意图、实拍证据或排版能力。

## 工具执行与完成状态

先读[制作参考](references/production.md)，并按[完整示例](assets/worked-example.md)替换成真实商品。先查看实际输入图片，再发现当前可调用的图像工具、读取其真实参数，确认参考图输入、编辑范围、输出获取和本任务特定能力。用户指定且已授权的工具优先；不得编造工具名、模型、参数、尺寸能力或额外付费重试预算。

具备工具时实际调用并查看结果，只有提示词不能算已生成。每张结果须对应准确原图；在授权范围和预算内修复，若同一失真持续出现或预算耗尽，停止并报告失败项。工具不可用时仍交付完整提示词、原图清单及布局，状态明确为 `not_generated`；已生成但无法查看像素时记为 `generated_unreviewed`，不能写 `verified`。

## 制作流程

1. 先建立模块清单：编号、要回答的购买问题、证据、图像类型、准确文案、裁切和输出。避免多张重复同一卖点，不能为填满详情页增加未经证实的好处。

2. 统一商品身份、背景色、可比较情况下的尺寸占比、光照和字体。干净主图可作为视觉基准，但细节模块仍须依据原始近照。

3. 调用真实参考图工具制作主图，再逐个制作有依据的模块。准确分配原图角色，不能从局部照片猜隐藏结构。工具无法准确写字时把底图和文案分开。

4. 有排版工具时把批准文案以可编辑方式合成，再从实际图片制作移动版本，保留该模块要解释的细节。裁切会丢失核心信息时重排，不能简单缩小成看不清的桌面长图。

5. 按桌面实际位置和合理手机宽度逐张查看，检查跨模块商品一致性、文字准确性与每项细节。只修问题模块；证据不足的模块明确待完成。

## 交付标准

交付按顺序命名的真实桌面／移动图片、实际生成的干净底图、可编辑文案／布局及模块证据表。每张记录真实尺寸、裁切和图文验收。缺证据或排字未解决的模块不能算完成的销售素材。
