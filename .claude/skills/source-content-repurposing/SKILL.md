# Source Content Repurposing

Use this when a DTC merchant needs a source-grounded repurposing pack containing finished native copy, source-to-output traceability and a reviewable distribution queue.

## Merchant inputs

Owned long-form source or transcript; factual evidence; rights; destination; audience; requested formats; brand voice and production capacity.

Separate supplied facts, observed evidence, assumptions and unavailable information. Request only missing inputs that change the decision; a partial evidence set supports a partial result, not invented measurements.

## Tools and fallback

Read supplied CSV, screenshots, page text or documents with available file tools. A browser or authorized read-only connector can verify current pages and provider documentation. No named commercial service, host registry or script is required. Without live access, use dated exports and label the access window; do not imply a live check. Verify current provider-specific formats and policies before implementing a platform change.

## Procedure

1. Extract a source ledger of claims, stories, quotations, demonstrations and useful instructions, preserving passage or timestamp IDs.

2. Choose atoms that stand alone and answer a real shopper question. Separate a source observation from an inference; do not invent personal experience to make a stronger hook.

3. Map each atom to a suitable output such as caption, carousel, short script or email excerpt. Preserve sufficient context for readers who never saw the source.

4. Draft actual variants with truthful hooks and a completed payoff. A curiosity gap must close; a numerical headline requires the matching sourced number.

5. Check each output against product facts, quote/asset permissions, offer freshness and brand tone. Do not turn a source warning into an endorsement by cropping its context.

6. Return finished copy plus a source-to-output matrix, asset needs and a feasible distribution queue. Track draft/review/published states and actual receipts separately.

7. For each short-video hook provide spoken words, the opening visual frame and the later source-backed payoff, including a muted-viewing option. For a caption paired with media, complement rather than merely repeat the visible scene. Produce contrasting hook hypotheses without calling fixed opening seconds an algorithm law.

## Deliverable

A source-grounded repurposing pack containing finished native copy, source-to-output traceability and a reviewable distribution queue.

Include input provenance and observation dates beside affected rows. Explain the decision and the uncertainty it depends on; preserve exclusions and unresolved rows so another operator can reproduce the result.

## Execution scope

Prepare the analysis and reviewable artifacts within the requested scope. Sending messages, publishing, changing audiences or budgets, signing terms and editing live store settings require authorization for that action. A proposed change is not a completed action; report completion only from provider or page readback. Do not copy credentials or customer contact details into reports.
