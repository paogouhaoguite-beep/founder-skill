# 内链与孤岛页审计

> 来自 [ShopChief](https://shopchief.ai/?utm_source=internal-link-audit&utm_medium=agent_skill&utm_campaign=commerce_skills&utm_content=skill_header) · 面向独立站与 DTC 卖家的 AI 运营工作流。可独立使用，无需 ShopChief 账号。

## 定位

本技能审计店铺页面之间如何互链,并返回修复清单:哪些页面被埋没或成为孤岛、哪些链接断链或成环、哪些锚文本在误导读者,以及具体新增哪些链接。内链分配发现路径与相关性;本技能度量的是可观察结构——解析出的 HTML 中的链接——并声明其边界。

**声明限制:** 本技能不计算、不估算、不编造 PageRank 类权重值。它只报告本次实际抓取解析得到的链接数量、深度与锚文本质量。

## 边界

- 页面可索引性、canonical、robots、sitemap 问题 → `site-seo-audit`。
- 为新内容计划设计内链结构(哪些页面该存在、概念上该如何互链) → `seo-content-research`。
- 多 URL 争抢同一查询 → `keyword-cannibalization`。

## 必备输入

| 输入 | 必需性 | 缺省处理 |
| --- | --- | --- |
| 站点域名 | 必需 | 追问 |
| 纳入审计的页面清单(或从 sitemap/首页抓取) | 建议 | 以首页 + sitemap 条目为种子,受声明的抓取范围/预算约束 |
| 优先页面(钱页:集合页、产品页、关键落地页) | 建议 | 从 URL 模式推断并声明 |

## 必须流程

1. **抓取。** 用 OnPage 内容解析 逐页解析内链与外链。探索样本可取 **100 页**，抓取前声明范围和预算。种子顺序:首页 → 顶部导航目标 → sitemap 条目 → 钱页。记录实际解析了哪些页;未抓到的页面不在证据范围内。
2. **构建链接图**(仅基于已解析页面)。计算:每页入链数、从首页出发的点击深度(沿内链)、每页出链数。
3. **深度报告。** 标出深度 ≥ 4 的钱页与深度 ≥ 6 的页面。深度按本次抓取的可达性计算;某页在抓取中不可达属于单独发现(见第 4 步),不是"无限深"。
4. **断链、重定向链、循环。** 来自解析结果:指向 404/410 的链接、经重定向链的链接(仅当解析暴露状态码时记录链路,否则标"状态未验证")、已解析页面之间的自引用或循环模式。对最高严重级条目用 OnPage 即时页面检查 实测复核(遵守预算上限)。
5. **孤岛页。** 出现在 sitemap 或用户清单、但未从任何已解析页面获得内链的页面。**必须说明所用发现渠道**(sitemap、首页抓取、用户清单),并说明孤岛判定是相对本次 ≤ 100 页抓取而言,不代表全站结论。
6. **锚文本分级。** 对每条被审计链接(或价值最高的子集):**描述准确**(符合来源语境和目标内容，同一目标可以自然使用不同锚文本)、**模糊**("点击这里"、"了解更多"、裸 URL)、**错配**(锚文本承诺的主题与目标页实际交付不符)。对每条被标记的链接给出修正锚文本。
7. **新增链接表。** 具体的新增建议:来源页 | 页面上的位置(版块/模块)| 目标 | 推荐锚文本 | 语义理由(该链接如何帮助读者或搜索引擎理解页面关系)。优先补向孤岛页或深层钱页的链接。不为凑数量在无语义关系的页面之间提议链接。

## 输出格式

1. **抓取范围声明** — 已解析页数、种子顺序、日期、是否触达上限。
2. **深度与孤岛报告** — 每个被标记页面:深度、入链数、状态。
3. **断链/重定向/循环发现** — 附验证状态。
4. **锚文本分级表** — 链接 | 当前锚文本 | 分级 | 建议锚文本。
5. **新增链接表** — 来源 | 位置 | 目标 | 推荐锚文本 | 语义理由。

## 失败处理

- 触达抓取上限:报告覆盖率(已知 Y 页中解析了 X 页),所有发现限定在已抓取集合。
- OnPage 内容解析 对某页失败:标注该页未解析,不得推断其链接。
- sitemap 不可达且无用户清单:说明孤岛检测仅限已抓取的图。
- 不得编造权重分数、抓取预算或解析中未观察到的链接数。
