# 商品单图转视频

把获准使用的商品静态图做成真实可播放的短视频；有兼容生成器时执行生成并检查成片。这项技能负责单图制作与验收，不只输出多镜头策划。

## 输入与镜头边界

先查看原图，再编写提示词。确认投放位置、时长、画幅、允许的运动、商品事实以及用户已给出的生成数量和预算。记录原图能证明的商品表面。正面图不能证明背面、底部、内部或开合机制；缺少这些素材时，优先保持商品朝向，让背景或光线轻微运动，或做不暴露新表面的轻微推近。

锁定包装、标签文字、轮廓、材质、颜色、闭合状态及商品数量。无证据时不演示液体、发热、防水、耐用性或机械性能。摄影机运动不得揭露未被证明的结构。每个镜头只规定一个主要动作、一个摄影机动作及稳定背景；精确文字用后期叠加。

## 执行制作

选工具或调用前阅读[制作执行说明](references/production.md)。核对当前工具是否支持图像条件输入、所需时长、画幅和上传方式。用户已经授权且数量和费用范围明确时直接执行，不重复确认常规步骤。提交受控数量的候选，保存任务标识并等待完成；遇到状态未知的超时，继续查询原任务。

有已授权的 Runway API 账号但没有连接器时，可使用随包[命令行脚本](scripts/runway_video.py)，提供提交、查询状态和下载功能。先阅读[配置与完整命令](references/runway-cli.md)。需要 Python 3.10+，API 密钥通过环境变量提供；提交命令默认只做离线检查，明确传入 `--execute` 才生成。执行沿用用户已授权的范围；已有回执会阻止重复提交，状态未知时先核对原任务，避免重复扣费。

通过允许的方式保存完成文件。观看完整视频，重点检查开头、中间、结尾和运动显露细节的时刻，对照原图核验文字、边缘、数量、阴影、反射及商品与背景的比例。标签变形、增加接缝、形状变化或凭空补出背面均应拒收。按具体缺陷修正运动并在剩余额度内再制作，不用不准确的商品画面凑数。

常规平移或缩放静态图也可能符合需求，但必须说明是静态图动画，不能称为真实三维转台。没有兼容生成工具时，交付绑定源图的完整提示词及请求规格，并明确“尚未生成”。

## 交付

有成片时交付视频文件和封面帧、原图与提示词记录、目标和实际尺寸/时长、任务状态及视觉验收结果。将可播放文件、被拒收候选和仅提示词交付分别标注。制作素材不自动包含发布。
