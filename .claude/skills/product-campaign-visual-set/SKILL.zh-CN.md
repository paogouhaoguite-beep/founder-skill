# 商品促销跨渠道整套视觉制作

从一次已批准活动制作网站横幅、邮件及社媒等完整素材组，确保商品身份、报价条件和期限一致。负责跨尺寸资产矩阵与逐图验收，单张广告主视觉或排期表不能代替整套素材。

## 所需输入

收集活动 ID、商品原图、已有主视觉（如有）、批准的优惠／代码／适用商品／排除项、带时区的起止时间、各语言准确文案、各渠道实际尺寸或裁切规则及品牌图形。已确认的促销事实与拟议视觉风格分开管理。

## 工具执行与完成状态

先读[制作参考](references/production.md)，并按[完整示例](assets/worked-example.md)替换成真实商品。先查看实际输入图片，再发现当前可调用的图像工具、读取其真实参数，确认参考图输入、编辑范围、输出获取和本任务特定能力。用户指定且已授权的工具优先；不得编造工具名、模型、参数、尺寸能力或额外付费重试预算。

具备工具时实际调用并查看结果，只有提示词不能算已生成。每张结果须对应准确原图；在授权范围和预算内修复，若同一失真持续出现或预算耗尽，停止并报告失败项。工具不可用时仍交付完整提示词、原图清单及布局，状态明确为 `not_generated`；已生成但无法查看像素时记为 `generated_unreviewed`，不能写 `verified`。

## 制作流程

1. 列出资产矩阵：渠道位置、比例／尺寸、语言、商品、文案、优惠及条件、期限和输出。折扣、时区或适用范围不明确时列为待确认，不能凭模糊日期计算倒计时。

2. 使用已有素材或真实参考图工具建立一张商品与风格基准，锁定商品、色调、光源和图形元素，先验商品准确性再扩展其他版位。

3. 逐个生成或重排版位，继续绑定同一商品原图与基准。横幅、邮件图、竖版社媒分别划分商品及文字区域，避免统一中心裁切导致条款或商品缺失。

4. 使用可用排版工具统一放置批准标题、代码及条件，尽量将准确优惠文字与生成画面分层。不能为了适应版式让不同图自创价格或到期时间。

5. 按各渠道实际观看尺寸检查真实输出，再将整套对照，核对商品、报价、代码、时间、条款可读性和裁切。只修失败版本，并如实标记仅生成底图、未排版或未复查项。

## 交付标准

交付实际各版位文件、已生成的共享干净主视觉、文案／布局源文件，以及含优惠、期限和版本的资产矩阵。区分全尺寸素材与预览缩略图；只有用户任务包含发布时才发布或排期。
