# Co Marketing Campaign Plan

Use this when a DTC merchant needs a co-marketing campaign agreement brief with value exchange, cost split, data boundaries and deduplicated measurement.

## Merchant inputs

Partner audiences and permission to collaborate; product compatibility; contribution budgets; channel access; offer terms; consent constraints; measurement plan.

Separate supplied facts, observed evidence, assumptions and unavailable information. Request only missing inputs that change the decision; a partial evidence set supports a partial result, not invented measurements.

## Tools and fallback

Read supplied CSV, screenshots, page text or documents with available file tools. A browser or authorized read-only connector can verify current pages and provider documentation. No named commercial service, host registry or script is required. Without live access, use dated exports and label the access window; do not imply a live check. Verify current provider-specific formats and policies before implementing a platform change.

## Procedure

1. Identify a customer-use occasion where both products naturally belong. Compare audience relevance and overlap rather than using follower count as partner value.

2. Choose a concrete format such as a jointly authored guide, bundle, workshop or referral campaign. Define what each party provides and receives.

3. Budget product, shipping, creative, staff and media costs separately; clarify who absorbs returns, refunds and stock shortages.

4. Draft an asset/approval schedule and a data-flow map. Separate permission to collaborate from permission to transfer subscriber data.

5. Create partner-specific links or codes while preserving one order truth. Define shared reporting and avoid adding each partner’s self-reported conversions.

6. Deliver a joint brief with named owners, cancellation conditions and a small pilot. Prepare outreach only where requested; the plan does not send pitches or commit partner funds.

## Deliverable

A co-marketing campaign agreement brief with value exchange, cost split, data boundaries and deduplicated measurement.

Include input provenance and observation dates beside affected rows. Explain the decision and the uncertainty it depends on; preserve exclusions and unresolved rows so another operator can reproduce the result.

## Execution scope

Prepare the analysis and reviewable artifacts within the requested scope. Sending messages, publishing, changing audiences or budgets, signing terms and editing live store settings require authorization for that action. A proposed change is not a completed action; report completion only from provider or page readback. Do not copy credentials or customer contact details into reports.
