# Merchant Brand Visual Review

## Inputs and access
Require design files or images, destination/size, audience, intended message, approved palette/fonts/logo files and reference examples. Design connectors are optional; local images and a review table suffice. If only a thumbnail exists, exact font or hex matching is unverified.

## Review protocol
Resolve the actual asset and version before judging it. Compare the intended message with the visible hierarchy: what appears first, supporting proof, product detail and action. Inspect alignment, spacing, crop, text density, logo proportions and consistency across pages at the intended viewing size.

Compare measurable brand properties only when actual source values are available. A thumbnail can suggest a mismatch but cannot establish precise colors, font family or contrast ratio. Separate visual observations, source-property checks and inferred usability effects. Aesthetic preference is not a defect unless linked to the brief.

Check text against verified facts and the allowed tone, including qualifiers and pricing conditions. Identify image-text collisions, unreadable labels and color-only distinctions. For each issue, state location, evidence, likely task impact and the smallest proposed change. Preserve working elements instead of proposing a wholesale redesign by default.

## Deliver
Return priority findings and page/element-specific recommendations, plus unverified properties and any needed assets. Read-only design inspection must not be committed as an edit. Editing or resolving reviewer comments requires the corresponding user scope; never mark a suggestion implemented from a text plan alone.
