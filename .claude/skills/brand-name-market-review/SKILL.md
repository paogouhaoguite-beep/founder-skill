# Brand Name Market Review

Use this when a DTC merchant needs a market-by-market brand-name screening matrix with linguistic fit, domain observations and unresolved clearance questions.

## Merchant inputs

Candidate names; product category; origin story; target markets/languages; desired tone; domain candidates; merchant constraints and existing marks if supplied.

Separate supplied facts, observed evidence, assumptions and unavailable information. Request only missing inputs that change the decision; a partial evidence set supports a partial result, not invented measurements.

## Tools and fallback

Read supplied CSV, screenshots, page text or documents with available file tools. A browser or authorized read-only connector can verify current pages and provider documentation. No named commercial service, host registry or script is required. Without live access, use dated exports and label the access window; do not imply a live check. Verify current provider-specific formats and policies before implementing a platform change.

## Procedure

1. Assess meaning, pronunciation, spelling, recall and category fit separately for each target market. Preserve uncertainty about unfamiliar slang or dialects.

2. Distinguish generic/descriptive/suggestive characteristics as screening observations, not a legal registrability verdict.

3. Test spoken-to-written confusion and diacritics/transliteration with realistic customer scenarios. Avoid treating English sound associations as universal.

4. Check dated domain and public name-use evidence through appropriate sources. Domain availability does not establish trademark clearance, and a marketplace listing does not establish seller authority.

5. Compare candidates using merchant priorities and explicit tradeoffs; do not rank by an invented universal weighted score or extension prestige.

6. Return a shortlist, linguistic review gaps, dated domain observations and separate professional clearance questions before spending on registration or launch.

7. Set merchant-specific criteria before generating candidates; explore descriptive, coined, evocative and other relevant directions before narrowing. Use pairwise tradeoffs and spoken/recall checks. Do not impose token-efficiency, AEO-first, alphabet-only or fixed-letter rules, and never label a screen as legally defensible clearance.

## Deliverable

A market-by-market brand-name screening matrix with linguistic fit, domain observations and unresolved clearance questions.

Include input provenance and observation dates beside affected rows. Explain the decision and the uncertainty it depends on; preserve exclusions and unresolved rows so another operator can reproduce the result.
