# Worked example

All names, inputs and results below are synthetic.

Input: Candidates “TideCup” and “TideKüp” for English-speaking buyers; brand values easy word-of-mouth. Expected test asks a listener to spell each name, records results and checks actual domains. If 4/5 test listeners spell TideCup correctly and 1/5 spell TideKüp, report this tiny directional sample, not a market-wide preference. Neither candidate is declared legally cleared.

## Acceptance scenarios

1. Given a domain is available but a similar mark is observed, flag the distinct trademark review instead of approving the name.

2. Given no fluent reviewer is available for a target language, keep cultural meaning checks pending.
