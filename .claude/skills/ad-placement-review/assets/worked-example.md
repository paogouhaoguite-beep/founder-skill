# Worked example

All names, inputs and results below are synthetic.

Input: Placement A spent $120 in a mature 14-day window with no orders; merchant test loss cap is $100. B spent $20 yesterday with a 7-day conversion lag. C has documented content that violates the brand’s policy. Expected: review A for efficiency exclusion, keep B pending maturity, and flag C for suitability regardless of ROAS. No claim that all apps are low quality.

## Acceptance scenarios

1. Given a placement report covers only 70% of spend, state the unobserved 30% rather than claiming a complete account audit.

2. Given exclusion would also block an important legitimate placement via a shared domain, narrow the rule or disclose the tradeoff.
