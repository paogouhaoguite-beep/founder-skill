# Worked example

All names, inputs and results below are synthetic.

Input: A rainwear brand consistently writes “light rain”, calls its jacket “Harbor Shell”, and uses short practical sentences. A draft says “The ultimate waterproof miracle for every storm.” Expected rewrite: “Meet Harbor Shell. A light layer for light rain.” Glossary preserves the exact model name and forbids replacing light-rain protection with waterproof. Support tone example: “Your order is delayed. The updated dispatch date is Friday.” This is calmer than the campaign voice.

## Acceptance scenarios

1. Given only a new brand name and no existing corpus, label voice attributes proposed and ask for approval; do not invent past posts.

2. Given two approved names for one SKU, flag the naming conflict and retain SKU mapping before rewriting product labels.
