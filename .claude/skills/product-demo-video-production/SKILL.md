# Product Demo Video Production

Create a finished demonstration that accurately shows how the product is used. This owns mechanism fidelity, shot production and render verification, not just the edit plan.

## Establish what can be demonstrated

Read the supplied manual, merchant facts and footage. Map each claimed action to evidence: setup state, hand/contact position, trigger, visible response and reset. Distinguish product operation from performance proof. A generated clip of an action does not establish that the physical product performs it.

Collect target placement, duration, ratios, narration language, available footage/references and the user's tool/count/budget scope. Ask only for a missing fact that blocks a truthful step. Do not infer a hidden latch, an absent button, cooling/heating speed, load capacity or a product result from marketing adjectives.

## Produce the sequence

Build the full spoken script and shot timeline from the actual operating order. Retain real footage for mechanism-critical moments. Use generation for suitable establishing scenes, isolated backgrounds or clearly illustrative transitions; keep mechanism evidence anchored to source footage. When real footage is unavailable, generate only supported visual actions and mark the result illustrative. An unsupported critical step remains a capture request rather than an invented mechanism.

Read [production execution](references/production.md), inspect available generator/editor/audio tools and run the authorized production steps. Generate missing approved visuals, await their task results, assemble the timeline, record or synthesize authorized narration, align captions to measured audio and render the requested output. Keep voice permissions and source rights explicit. Reuse authorization already supplied; do not stop at a script when the means and scope to produce the video are available.

Review the complete rendered sequence for correct order, continuous hand/object contact, real product state, honest timing and legible instructions. Do not cut away the essential operation or speed it up in a way that implies unproven performance. Distinguish editorial shortening from actual operation time.

## Deliver

Return the playable file, full script, source-to-shot map, capture/generation status, actual media metadata and any unsupported step. If no production tools are available, provide the complete edit/generation handoff and explicitly report no video produced. Keep publication and performance claims separate from production completion.
